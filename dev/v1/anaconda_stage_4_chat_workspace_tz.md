# Техническое задание — Этап 4
# ANACONDA Chat Workspace

## Внутреннее рабочее пространство компании

---

## 1. Цель этапа

Разработать отдельную страницу Chat Workspace — центральное рабочее пространство компании внутри ANACONDA.

Главная задача:

показать и подготовить ядро системы, где сотрудники работают не в разрозненных мессенджерах, а внутри единой операционной среды.

Это не просто чат.

Это:

- центр управления коммуникациями
- внутренняя операционная лента
- контроль клиентов и задач
- рабочая поверхность отделов
- управляемая среда руководителя

Главная мысль:

**ANACONDA превращает переписки, задачи, согласования и клиентскую работу в единую управляемую систему.**

## 7. Центральная рабочая лента

# Main Feed

Показываем:

- сообщения
- системные события
- задачи
- комментарии
- внутренние согласования
- счета
- изменения статусов
- уведомления
- AI рекомендации

Пример:

- клиент написал
- менеджер ответил
- выставлен счет
- бухгалтер подтвердил оплату
- руководитель увидел статус

Это должна быть единая timeline-лента действий.

## 15. Анимации

### Использовать

- panel transitions
- channel expand
- message reveal
- inline task updates
- approval status transitions
- soft notifications

### Не использовать

- flashy effects
- gaming-like motion
- distracting animations

### Mobile

На mobile:

- workspace превращается в последовательные контекстные экраны
- сначала каналы
- затем feed
- затем context panel

Не пытаться впихнуть desktop-layout целиком.
