# Техническое задание — Этап 1 # ANACONDA Public MVP  ## Главная страница + Контакты  ---  ## 1. Цель этапа  Разработать первую production-ready версию сайта ANACONDA.  Сайт должен:  - объяснять продукт простым русским языком; - показывать превращение хаоса в единое окно; - быстро работать на desktop и mobile; - собирать заявки на бесплатный аудит; - выглядеть как современный B2B / enterprise продукт; - быть готовым к дальнейшему расширению страниц.  Главная мысль сайта:  **ANACONDA не заменяет бизнес-системы грубо. Она аккуратно встраивается в действующую инфраструктуру, собирает разрозненную информацию в единое окно и помогает компании постепенно перейти к современному управлению, автоматизации и AI.**  ---  ## 2. Технологический стек  ### Frontend  - Next.js 14+ - React 18+ - TypeScript - Tailwind CSS - Framer Motion - SVG для схем и потоков - CSS animations только там, где они легче Framer Motion  ### Backend  - FastAPI - Pydantic v2 - PostgreSQL - Psycopg 3  ### Runtime  - Docker - Docker Compose - Nginx в production - `.env` / `.env.prod` contract  ### Quality  - ESLint - TypeScript strict mode - Prettier - backend lint/test - Lighthouse check - mobile responsive QA  ---  ## 3. Страницы Этапа 1  ### `/` — Главная страница  Основные блоки:  1. Header 2. Hero chaos → order 3. Боли бизнеса 4. Как ANACONDA собирает источники 5. Единое окно менеджера 6. Как работает ANACONDA 7. Уровни внедрения — teaser 8. Бесплатный аудит 9. Footer  ---  ### `/contacts` — Контакты  Основные блоки:  1. Заголовок 2. Быстрые кнопки связи 3. Форма заявки 4. Контакты компании 5. Дополнительный CTA на аудит  ---  ## 4. Header  ### Содержимое  - логотип ANACONDA / OSNOVA - меню:   - Как работает   - Внедрение   - Аудит   - Контакты - CTA-кнопка: `Заказать аудит`  ### Поведение  - sticky header - blur / glass effect при скролле - mobile burger menu - закрытие меню после клика по якорю  ---  ## 5. Hero Section  ### Заголовок  # ANACONDA собирает хаос бизнеса в единое окно  ### Подзаголовок  Telegram, почта, звонки, Excel, 1С и старые базы перестают жить отдельно. ANACONDA объединяет их в рабочее окно, где менеджер видит клиента, историю, счета и следующие действия.  ### CTA  - Заказать бесплатный аудит - Посмотреть как работает  ---  ## 6. Hero Animation — Chaos → Order  ### Desktop  Источники:  - Telegram - WhatsApp - MAX - Email - Excel - 1С - База данных - Звонки  В центре — окно ANACONDA.  ### Последовательность анимации  1. Источники мягко появляются 2. Линии данных идут к центру 3. Появляется центральное окно системы 4. Внутри появляется чат менеджера 5. Сообщения помечаются источником 6. Справа появляется карточка контрагента 7. Появляется действие `Выставить счет`  ### Требования  - использовать transform + opacity - не анимировать layout-heavy свойства - SVG-линии допустимы - без Three.js на этапе 1 - без тяжелых particle effects - анимация должна объяснять, а не отвлекать  ### Mobile  - упрощенная анимация - fade-in - последовательное появление карточек - без тяжелого scroll-driven motion - приоритет: скорость и читаемость  ---  ## 7. Блок “Боли бизнеса”  ### Заголовок  # Когда системы не связаны, бизнес теряет деньги  ### Карточки  1. Заявки теряются 2. Данные дублируются 3. Руководитель не видит картину 4. Сложно передавать клиентов  Формат:  иконка + короткое понятное описание  ---  ## 8. Блок “Единое окно”  ### Заголовок  # Менеджер работает не в десяти программах, а в одном окне  ### Макет  - слева: список клиентов - центр: чат - справа: карточка контрагента  ### Правая панель  - задолженность - последний счет - история оплат - товары - кнопка `Выставить счет` - кнопка `Передать клиенту`  ---  ## 9. Блок “Как работает ANACONDA”  ### Заголовок  # Мы не ломаем вашу систему. Мы аккуратно встраиваемся в нее.  ### Суть  ANACONDA подключается к уже существующей инфраструктуре: 1С, CRM, почте, телефонии, мессенджерам и базам данных.  Сначала система собирает данные в единое окно.  Затем помогает навести порядок.  После этого можно постепенно переходить на более современные процессы, автоматизацию и AI.  ### 3 шага  1. Подключаемся 2. Собираем порядок 3. Развиваем систему  ---  ## 10.
