# Техническое задание — Этап 2 # ANACONDA Implementation Levels  ## Отдельная страница уровней внедрения  ---  ## 1. Цель этапа  Разработать отдельную страницу, которая наглядно объясняет клиенту, что внедрение ANACONDA происходит поэтапно, без резкой замены существующих систем.  Главная задача:  показать, что ANACONDA внедряется постепенно — от простого единого окна для менеджеров до полноценной AI-системы компании.  Страница должна:  - снимать страх «нам сломают 1С»; - объяснять путь внедрения простым языком; - помогать собственнику выбрать уровень входа; - показывать рост ценности на каждом этапе; - закрывать пользователя на бесплатный аудит.  Главная мысль:  **Мы не продаем резкую замену инфраструктуры. Мы строим управляемый путь развития бизнеса — шаг за шагом.**  ---  ## 2. Технологический стек  ### Frontend  - Next.js 14+ - React 18+ - TypeScript - Tailwind CSS - Framer Motion - SVG diagrams - responsive timeline components  ### Backend  На Этапе 2 отдельный backend не требуется.  Используется существующий:  - FastAPI - existing lead API - existing contact form flow  ### Runtime  - Docker - Docker Compose - Nginx  ### Quality  - ESLint - strict TypeScript - Lighthouse - responsive QA  ---  ## 3. Страница Этапа 2  ### URL  `/implementation-levels`  ## Основные блоки  1. Header 2. Hero 3. Почему поэтапное внедрение 4. Timeline из 5 уровней 5. Детальный блок каждого уровня 6. Сравнение: было → стало 7. Для кого подходит каждый уровень 8. CTA на бесплатный аудит 9. Footer  ---  ## 4. Hero Section  ### Заголовок  # Внедрение без хаоса  ### Подзаголовок  ANACONDA не требует ломать текущую систему.  Мы подключаемся к действующей инфраструктуре, собираем порядок и постепенно переводим бизнес на современную управляемую модель.  ### CTA  - Заказать бесплатный аудит - Посмотреть уровни внедрения  ### Визуал  Горизонтальная схема:  хаос → единое окно → CRM → аналитика → автоматизация → AI-помощник  Важно:  визуал должен показывать эволюцию, а не “революцию”.  ---  ## 5. Блок “Почему поэтапно”  ### Заголовок  # Почему нельзя внедрять всё сразу  Карточки:  1. Риск остановки бизнеса 2. Сопротивление сотрудников 3. Ошибки интеграции 4. Потеря контроля  Текст:  Поэтапное внедрение снижает риски, позволяет быстро получить результат и не ломает действующие процессы.  ---  ## 6. 5 уровней внедрения  Каждый уровень должен быть отдельным визуальным блоком.  Формат:  - номер уровня - название - какая боль решается - что подключаем - что получает менеджер - что получает руководитель - результат - CTA  ---  ## 7. Уровень 1  # Единое чат-окно  ### Решаем  Потерю заявок и хаос коммуникаций.  ### Подключаем  - Telegram - WhatsApp - MAX - Email - звонки - сайт - формы заявок  ### Менеджер получает  единое рабочее окно.  ### Руководитель получает  контроль входящего потока.  ### Результат  клиенты перестают теряться.  ---  ## 8. Уровень 2  # CRM + интеграция с 1С  ### Решаем  разрыв между продажами и учетом.  ### Подключаем  - клиенты - счета - оплаты - остатки - товары - документы - ERP / CRM / 1С  ### Менеджер получает  быструю работу без ручного ввода.  ### Руководитель получает  прозрачность процессов.  ### Результат  снижение операционного хаоса.  ---  ## 9. Уровень 3  # Аналитика для руководителей  ### Решаем  отсутствие управленческой картины.  ### Подключаем  - воронки - продажи - KPI - конверсии - проблемные зоны - отчеты  ### Руководитель получает  реальную картину бизнеса.  ### Результат  управление на цифрах, а не на ощущениях.  ---  ## 10. Уровень 4  # Умная автоматизация  ### Решаем  ручные рутинные процессы.  ### Подключаем  - расшифровку звонков - анализ переписок - контроль просрочек - автоматические уведомления - контроль рисков - персональные сценарии  ### Результат  скорость работы и снижение ошибок.  ---  ## 11. Уровень 5  # AI-помощник компании  ### Решаем  поиск знаний и экспертную поддержку сотрудников.  ### Подключаем  - внутреннюю документацию - регламенты - историю работы с клиентами - аналитику - корпоративную базу знаний  ### AI умеет  - отвечать как эксперт - подсказывать сотрудникам - помогать руководителям - анализировать ситуацию по клиенту  ### Результат  внутренний корпоративный интеллект.  ---  ## 12. Блок “Было → Стало”  ### Заголовок  # Что меняется после внедрения  Сравнение:  ## Было  - хаос - ручной ввод - потеря клиентов - Excel и личные чаты - непрозрачность  ## Стало  - единое окно - прозрачные процессы - контроль руководителя - автоматизация - AI-поддержка  Формат:  визуальная двухколоночная секция.  ---  ## 13. Блок “Кому подходит”  ### Для собственника  контроль, безопасность, сохранение базы.  ### Для коммерческого директора  скорость, KPI, управляемость отдела продаж.  ### Для CTO  безопасная интеграция без разрушения инфраструктуры.  ### Для главбуха  чистая работа с 1С без лишнего вмешательства.  ---  ## 14. CTA — Бесплатный аудит  ### Заголовок  # Не знаете, с какого уровня начать?  Мы бесплатно посмотрим текущие процессы и покажем, какой уровень внедрения даст максимальный эффект быстрее всего.  ### Кнопка  `Заказать бесплатный аудит`  Используется существующий LeadForm.  ---  ## 15.
