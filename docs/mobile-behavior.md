# Mobile Behavior

## Principles

- Mobile is not a desktop shrink.
- No horizontal scroll.
- CTA remains easy to reach.
- Motion is shorter and lighter.
- Complex workspace layouts become stacked views.

## Stage behavior

- Landing: simplified chaos-to-order cards and readable copy.
- Implementation levels: vertical stack.
- Demo: client → chat → card → actions → AI hints.
- Workspace: spaces → feed → context panel.
