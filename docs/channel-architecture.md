# Channel Architecture

Workspace structure:

```text
Space → Channel → Feed events → Context panel
```

Default spaces:

- Клиенты
- Продажи
- Закупки
- Бухгалтерия
- Руководство
- Снабжение
- Производство
- Сервис
- Внутренние согласования
- Системные события

The UI must explain company operations, not imitate a consumer messenger.
