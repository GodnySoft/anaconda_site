# ANACONDA Public MVP  ## Scope  Stage 1 implements `/` and `/contacts`.  The landing explains `Chaos → Control`: fragmented messengers, calls, Excel, 1C, CRM, and old databases become one controlled work window.  ## Public surface  - `/`: hero, business pains, unified manager window, implementation teaser, audit CTA. - `/contacts`: contact methods, lead form, audit CTA. - Stable API: `GET /api/v1/health`, `POST /api/v1/leads`.  ## Design rules  - Quiet Power: serious, calm, enterprise, high-trust. - Use Obsidian Black, Ivory White, Noble Green, Steel Gray. - Motion must explain the product, not decorate it. - Mobile is a simplified composition, not a desktop shrink.
