# Timeline Logic

The implementation timeline shows evolution, not revolution:

```text
хаос → единое окно → CRM + 1С → аналитика → автоматизация → AI-помощник
```

Each level must show:

- business pain;
- connected systems;
- manager outcome;
- leadership outcome;
- implementation result.

Motion uses progressive reveal and level highlighting only. Heavy 3D, aggressive parallax, and particle effects are not allowed.
