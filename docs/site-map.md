# Карта публичного сайта

## Назначение

Этот документ фиксирует публичную структуру сайта инструмента ANACONDA в составе проекта ОСНОВА.
Текущий приоритет — закрытие Этапа 1 / Public MVP.

## Маршруты

- `/`
  Главная страница Public MVP. Объясняет продукт, показывает схему `хаос -> единое окно`, собирает заявки на аудит.
- `/contacts`
  Контактная страница Этапа 1. Даёт быстрые каналы связи и повторно использует lead flow.
- `/implementation-levels`
  Черновой маршрут Этапа 2. Не является текущим критическим deliverable.
- `/demo`
  Черновой маршрут Этапа 3.
- `/workspace`
  Черновой маршрут Этапа 4.
- `/chatbot`
  Черновой маршрут Этапа 5.

## Текущий продуктовый фокус

1. Довести `/` до соответствия `../dev/v1/anaconda_stage_1_public_mvp_tz.md`.
2. Довести `/contacts` до полноценного контактного контура Этапа 1.
3. Удерживать единый контракт lead form через `POST /api/v1/leads`.

## Зависимости

- frontend: `../web/pages`
- shared components: `../web/components`
- lead API contract: `./lead-api-contract.md`
- локальный runtime: `../docker-compose.yml`, `../Makefile`
